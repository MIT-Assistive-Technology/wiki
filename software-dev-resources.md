## Environment & Packaging
[pip + venv] (https://docs.python.org/3/library/venv.html) – classic Python dependency/env tooling, still ubiquitous.
[.env + python-dotenv] (https://pypi.org/project/python-dotenv/) – store API keys/secrets outside your code.

## Containers
[Docker] (https://docs.docker.com/get-started/) – package your app with its dependencies for consistent environments.

## Code Quality & Testing
[pytest] (https://docs.pytest.org/) – standard Python testing framework.
[ruff] (https://docs.astral.sh/ruff/) – fast linter + formatter, replaces flake8/black/isort.

## Agent Building
[Anthropic Agent SDK / Claude Code SDK] (https://docs.claude.com/) – official tool-loop primitives for building Claude-based agents.
[MCP (Model Context Protocol)] (https://modelcontextprotocol.io/) – standardized way for agents to connect to tools/data sources.
[Langfuse] (https://langfuse.com/docs) – open-source alternative for LLM/agent observability.
